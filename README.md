# Naruto Bedrock Addon

An in-progress Minecraft Bedrock addon designed with Android/mobile performance in mind.

## Current foundation

- Behavior pack and resource pack manifests.
- Initial script-based chakra score (starts at 100 and regenerates by 2 per second).
- Ninja XP score and a level display (XP progression is a scaffold; XP rewards and jutsu costs are not implemented yet).
- Chakra and XP shown in the action bar.

## Planned development order

1. Import/load test and fix any manifest or Script API errors.
2. Add controlled chakra costs, cooldowns, and jutsu scroll learning.
3. Add elemental jutsu and signature techniques.
4. Add dōjutsu, clans, tailed beasts, and jinchūriki systems.
5. Add assets, animations, sound, bosses, and mobile performance testing.

## Important

This is an early development foundation, not a finished Naruto addon. It has not yet been tested in Minecraft on a device. Script API availability depends on the Minecraft Bedrock version installed. Test in a copied creative world first and enable any required Beta APIs only if Minecraft reports that they are needed.
