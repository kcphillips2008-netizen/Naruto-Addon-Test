# Naruto Bedrock Addon

Early development build targeting Minecraft Bedrock 1.26.x and Android/mobile.

## In this build
- Behavior pack and resource pack.
- Script API dependency declared as @minecraft/server 2.7.0.
- Chakra scoreboard initializes at 100 and regenerates by 2 each second.
- Ninja XP scoreboard and a level/action-bar display (XP rewards are not implemented yet).

## Testing
Import the .mcaddon into Minecraft and activate both packs in a copied Creative world. If Minecraft reports a script/API dependency or manifest error, send the exact error or a screenshot.

This is a foundation/test build, not a finished Naruto addon. It has not yet been tested inside Minecraft on a device.
